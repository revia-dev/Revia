# Architecture Decision Records

Short, immutable records of the significant architectural choices in Revia and
*why* they were made — so the reasoning survives the people who made it. New
decisions get a new numbered file; superseded ones are marked, not deleted.

Format: [Michael Nygard's ADR template](https://github.com/joelparkerhenderson/architecture-decision-record).

| # | Title | Status |
|---|---|---|
| [0001](0001-offline-first-sync.md) | Offline-first sync via outbox + server-wins | Accepted |
| [0002](0002-token-auth.md) | Token-based auth: JWT access + rotating hashed refresh tokens | Accepted |
| [0003](0003-observability.md) | Observability: structured logs, OpenTelemetry, health, ProblemDetails | Accepted |
